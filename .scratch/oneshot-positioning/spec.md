# spec · 定位改一次性配置 + 显式更新/回归

## 问题

持续收敛姿态下，WDC 的默认叙事把「机器随时与声明一致」当目标态：`wdc sync` 框架为「日常一键同步」、漂移检测/triage 构成日常纪律、多机以「随时全绿」为对等目标。真机实录（坑1–18）显示暴露面最大处恰是持续收敛在活机器上的反复触碰——升级竞态（坑14）、漂移处置打地鼠（json-semantic-sync）、异质环境适配（火绒/GBK/MSYS/网络波动）全部发生在「再次收敛」时点，而首次全新机器的一次性收敛是被打熟的路。主人 2026-11-21 自述痛点：不同环境适应性差、易碰坏已有工作环境；当日对照 microsoft/WindowsDeveloperConfig（一次性 opinionated 安装器 + 每项设置 undo 文档 + CI 矩阵）后定夺改定位。

## 定夺

主人 2026-11-21 定夺（本会话两步确认）：

- 默认改**一次性配置**：bootstrap 跑一次即休眠，机器日常归用户、漂移合法。
- 后续只做显式手动的**更新**（拉新声明再跑）与**回归**（漂移后拉回**当前**声明状态）——「回归」方向主人钉死为收回敛，非 uninstall/回滚；退出路径另议（上轮候选①悬置）。

## 方案

纯姿态与叙事变更，**零行为变更**（ADR-0009）：

- README：首段定位语、`wdc plan`/`wdc sync`/bootstrap 命令行、重跑口径、使用与改造改新叙事
- GLOSSARY：首段补姿态；新词条「一次性配置」「更新」「回归」；bootstrap/机器对等/分流三词条轻触
- scripts/wdc.ps1：sync 总览与详解、plan 总览三处帮助文本改口径（命令名/旗标/退出码不动，cli-parity 契约无涉）
- docs/forking.md：「日常跟随上游」标题改手动口径
- CHANGELOG：Unreleased 记 Changed

机制全部原样：bootstrap 幂等、渲染拷贝、收敛账本快速路径、运行锁、续跑任务、ADR-0007 移除清单收敛-only 语义。

## 边界

- LDC 姊妹仓定位不随本批联动（双边最优化，主人另定）
- 多机「随时全绿」承诺放弃：一致性只在各机手动更新/回归时点对齐
- 不做 uninstall/退出路径（另议）；不改 sync 命令名（改名成本与肌肉记忆不抵收益）
